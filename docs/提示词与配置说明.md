# 提示词与配置说明

项目面向中文学习：提示词、人工阅读的说明、导出报告、运行错误和解释性注释优先中文。
代码类名、JSON 字段、环境变量、状态枚举、模型名称保留原标识，避免翻译后破坏协议。
第三方许可证保留上游原文，README、LICENSE 等通用文件名保留，正文说明使用中文。

## 两份提示词

- `src/main/resources/prompts/规划智能体.txt`：把原始需求和实际检索片段转换为配置，
  定义参数范围、总尝试次数、默认规则引用和澄清条件。
- `src/main/resources/prompts/审核智能体.txt`：核对需求、配置和真实记录，区分程序结果和审核结果，
  明确引用格式及唯一一次修订条件。

Java 分别通过 `PlannerAgent` 与 `ReviewerAgent` 读取这两个中文文件名，
打包时以 UTF-8 保存到 JAR。改名后必须同步修改 Java 中的资源名称。
不要把 JSON 的 `scenarioType` 改成中文字段，也不要把 `APPROVED` 改成中文枚举；
说明这些标识是什么意思即可。

## 对话服务与向量服务

`AFL_CHAT_*` 用于两个角色的对话调用；`AFL_EMBEDDING_*` 用于知识和查询的向量化。
能聊天不代表能返回向量。Embedding 地址必须是供应商给出的有效 HTTPS Base URL，
模型必须是该供应商确实支持的向量模型标识，不能因为对话配置成功就直接照抄对话模型名。

密钥只留在被忽略的 `.env`；检查时只输出是否配置和脱敏结果。
修改 `.env` 后需要重启本项目进程，不要停止其他项目服务。
